如何订阅到日历应用？

  1. iOS / macOS 日历：在 Safari 中直接点击“订阅”按钮唤起，或复制链接后在日历应用中选择“新建日历订阅”并粘贴。
  2. Google Calendar：在网页端左侧边栏找到“其他日历” → “+” → “通过 URL 添加”，粘贴链接。
  3. Outlook：打开日历 → “添加日历” → “从 Web 订阅”，粘贴链接。
